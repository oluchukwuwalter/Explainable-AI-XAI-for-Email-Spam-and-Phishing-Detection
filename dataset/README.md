# Email_Phishing_Project
An Explainable AI for Email Spam and Phishing Detection Based n Hybrid Transformer-XGBoost Framework
# Dataset Documentation

This directory contains the datasets used in the development and evaluation of the **Explainable Email Spam and Phishing Detection System Based on a Transformer–XGBoost Hybrid Framework**.

Due to the large size of the original and processed datasets, the complete dataset files are **not included in this GitHub repository**. Instead, this document provides the original sources, dataset descriptions, processing information, directory structure, and references required to reproduce the experimental pipeline.

---

## 1. Datasets Used

The study uses three principal email corpora:

1. **SpamAssassin Public Corpus**
2. **CEAS 2008 Spam Dataset**
3. **Enron Email Dataset**

These datasets were combined and processed to construct the email corpus used for training, validation, testing, and explainability experiments.

---

## 2. SpamAssassin Public Corpus

### Description

The SpamAssassin Public Corpus is a publicly available collection of legitimate (ham) and unsolicited (spam) email messages. It was used as one of the sources for developing the spam/ham classification dataset.

### Source

Apache SpamAssassin:

<https://spamassassin.apache.org/downloads.html>

### Role in This Project

The dataset was used for:

- Spam/ham classification
- Text preprocessing
- Feature extraction
- Model training and evaluation

### Local Processing

The downloaded corpus was processed and converted into a structured format for integration with the other email datasets.

Processed files generated during the study are not included in the repository because of their size.

---

## 3. CEAS 2008 Spam Dataset

### Description

The CEAS 2008 Spam Dataset was associated with the Spam Challenge conducted as part of the Fourth Conference on Email and Anti-Spam (CEAS 2008).

### Original Source

Conference on Email and Anti-Spam (CEAS) 2008:

<https://www.ceas.cc/2008/>

### Official CEAS Conference Archive

<https://ceas.cc/index.html>

### Role in This Project

The CEAS 2008 dataset was used for:

- Email spam classification
- Data preprocessing
- Feature extraction
- Transformer model training
- XGBoost classification
- Explainability analysis

### Local Dataset

The locally downloaded dataset is maintained outside the GitHub repository because of its large file size.

The project uses:

```text
ceas_08.xlsx
```

Researchers wishing to reproduce the experiments should obtain the dataset from the original CEAS source and comply with the applicable terms of use.

---

## 4. Enron Email Dataset

### Description

The Enron Email Dataset is a large publicly available corpus of email messages associated with Enron employees. The CMU-hosted version contains approximately 526,000 messages.

### Source

Carnegie Mellon University:

<https://www.cs.cmu.edu/~enron/>

### Role in This Project

The dataset was used as an additional source of legitimate and spam-related email content and contributed to the construction of the combined email corpus.

### Local Processing

The original Enron corpus was converted into a structured tabular representation and subsequently processed as part of the data preparation pipeline.

Due to the large size of the original and processed files, they are not stored in this repository.

## 6. Dataset Processing Pipeline

The datasets were processed through a sequential data preparation pipeline before being used for model training and evaluation.

The overall workflow was:

```text
Original Datasets
       │
       ▼
Data Extraction
       │
       ▼
Data Cleaning
       │
       ▼
Data Standardisation
       │
       ▼
Duplicate Removal
       │
       ▼
Dataset Integration
       │
       ▼
Train / Validation / Test Split
       │
       ▼
Transformer Tokenisation
       │
       ▼
Model Training
       │
       ▼
Evaluation and Explainability
```

The preprocessing stage included the removal of duplicate records, handling of missing or inconsistent values, text cleaning, HTML processing, URL handling, and standardisation of the relevant email fields.

The resulting datasets were subsequently used in the Transformer and Transformer–XGBoost experiments.

## 8. Dataset Reproduction

To reproduce the dataset preparation process:

1. Obtain the original datasets from the sources documented in this README.
2. Place the downloaded datasets in:

```text
datasets/raw/
```

3. Open the relevant preprocessing notebook from:

```text
notebooks/
```

4. Execute the preprocessing workflow sequentially.
5. The processed datasets will be generated under:

```text
datasets/processed/
```

6. The resulting datasets can then be used by the model training and evaluation notebooks.

The repository therefore provides the computational workflow required to reconstruct the processed datasets without redistributing the large original dataset files.
